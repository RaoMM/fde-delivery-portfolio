# 可运行演示版

## 启动

在终端进入本目录后执行：

```bash
python3 rag_server.py
```

浏览器访问 `http://127.0.0.1:8080`。

## 运行条件

- macOS；
- Python 3；
- 浏览器；
- 不需要飞书登录，也不需要随包提供模型密钥。

本包内置课堂脱敏知识快照。未配置 `DEEPSEEK_API_KEY` 时，系统返回清晰标识的“依据草案”；配置企业自有密钥后，才会调用模型对检索到的证据作受控整理。密钥不得写入本文件夹、代码仓库或日志。

## 演示范围

- 员工流程查询：展示依据、风险标记和内部参考；
- 直接顾客高风险、实时数据或资料不足：显示“需人工确认”，不形成对客结论；
- 本机接口中的入站、消息回写和人工确认接口仅为 Mock 契约，不连接真实客服渠道。

## 不属于本演示包的内容

飞书知识刷新、真实客服渠道、订单/库存系统、账号权限和正式部署配置均不包含在本包。它们是生产部署的后续工作，见 `../06-完整文档链接与生产计划/生产部署与下一步计划.md`。
