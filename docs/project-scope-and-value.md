# 最终范围与业务价值

> 本文件是本交付包的最终范围口径。目录内 Day1、Day2 文件保留为需求与排期的过程证据；如与本文件存在范围表述差异，以本文件及 Day4、Day5 验收材料为准。

## 1. 项目目标

为美妆零售企业的客服与导购提供内部知识协作能力：员工可查询已授权的流程规范并查看原文依据；对直接顾客高风险咨询、实时数据需求和资料不足问题，系统停止形成对客结论并显示人工确认原因与可核对依据。

## 2. 当前已实现范围

| 模块 | 最终实现 |
|---|---|
| 知识源 | 课程提供的 5 份脱敏 Mock 流程资料，以版本化本地快照提供 39 个可检索片段。 |
| 检索与引用 | 返回命中文档、版本、章节、原文摘录和文档链接。 |
| 受控整理 | 员工流程查询可由模型基于检索证据整理；未配置模型时降级为明确标识的依据草案。 |
| 风险分流 | 对实时数据、疑似不良反应、复杂客诉、特殊使用条件、资料不足及内部配置索取执行停止或限制规则。 |
| 人工边界 | 对客回复始终由人工审核和发送；系统不自动转派、发送、赔付或作医疗判断。 |
| 验收 | 12 条可运行 Eval，覆盖员工知识查询、顾客风险、资料不足、空输入、模型异常与安全边界；复测 12/12 通过。 |

## 3. 本期不做

1. 不回答具体 SKU、成分配方、个体肤质适配或具体商品用法；目前资料未覆盖这些可核实事实。
2. 不接入真实客服渠道、订单、库存、价格、效期或售后系统，也不输出实时业务结论。
3. 不自动对客发送、自动转派、批准退换货、决定赔偿或作医疗/因果判断。
4. 不自动修改企业原始知识文档。

## 4. 业务价值与验收含义

本期验证的不是“AI 替客服解决消费者问题”，而是两类内部协作结果：

- 有依据的员工流程查询，得到可回看的内部参考；
- 不该下结论的问题，得到包含原因、已有依据和待核对项的人工确认提示。

因此，本期的有效结果是“内部协作闭环达成”，不等同于真实业务的自动答复率、顾客解决率或生产环境准确率。
