# 生产部署与下一步计划

## 课堂原型与生产交付的分界

本包证明的是“知识查询、来源追溯、风险分流”可以在课堂脱敏数据上跑通。它不等于已经具备真实业务上线条件。

## 生产部署前必须补齐

1. **知识与责任**：由业务方确认知识文档版本、内容负责人、更新审核与失效机制；补充已批准的 SKU、标签、备案和话术资料。
2. **账号与权限**：接入企业身份体系，按客服、导购、主管和知识维护者设置最小权限；顾客入口不得暴露内部流程。
3. **真实系统**：以 API 或 Webhook 接入客服渠道、订单、库存、工单与人工处理记录；实时数据不能由静态知识库替代。
4. **安全与审计**：模型密钥由企业密钥管理系统托管，不写入客户端、代码或日志；对知识读取、人工确认和对客发送保留必要审计记录。
5. **持续 Eval**：用经人工确认的真实业务样本定期复测引用完整性、风险识别与内部协作闭环；红线失败不能被平均通过率抵消。

## 建议推进顺序

1. 由业务方评审本包的范围、人工边界和 12 条 Eval；
2. 补充经批准的真实知识资料，完成权限与渠道接口确认；
3. 在隔离测试环境进行真实接口联调和扩展 Eval；
4. 小范围 MVP 试用，依据人工处理记录与员工反馈迭代；
5. 达到企业验收标准后再部署到正式环境。
